# 체크리스트: 시스템 시험 (SWE.6)
기준: A-SPICE 프로세스 SWE.6 (사용 중인 A-SPICE 버전의 문서와 대조해 갱신할 것), 스킬 `sw-system-test-design`, CLAUDE.md 2.1

| ID | 항목 | 근거 |
|---|---|---|
| ST-01 | 모든 소프트웨어 요구사항(`SWR`)에 시험 케이스가 하나 이상 연결되어 있다 (요구사항 커버리지 100%). | CLAUDE.md 2.1 |
| ST-02 | 요구사항 커버리지를 추적 매트릭스로 직접 확인했다 (누락·고아 시험 케이스 없음). | SWE.6 BP: 추적성 |
| ST-03 | 기능 요구사항과 비기능 요구사항(품질·제한·제약)이 모두 시험 대상에 포함되어 있다. | SWE.6 BP: 시험 케이스 선정 |
| ST-04 | 시험 케이스가 요구사항에서 도출되었고(블랙박스), 구현 내부에 의존하지 않는다. | SWE.6 BP |
| ST-05 | 동치 분할과 경계값 분석이 적용되었다. | 시험 기법 |
| ST-06 | 입력 조합이 많은 곳에 PICT 페어와이즈 조합을 썼고 모델이 보관되어 있다. | 시험 기법 |
| ST-07 | 각 시험 케이스에 목적, 전제 조건, 입력, 절차, 예상 결과가 있고 판정 기준이 명확하다. | SWE.6 BP: 시험 명세 |
| ST-08 | 기능 안전 요구사항(`SSR`)이 별도 문서의 요구사항으로 시험 대상에서 빠지지 않았다. | 프로젝트 규칙 |
| ST-09 | 시험이 실행되었고 결과(통과/실패)와 실패 조치가 기록되어 있다. | SWE.6 BP: 결과 기록 |
| ST-10 | 시험이 재현 가능하다 (환경, 도구 버전, 절차 기록). | SWE.6 BP: 재현성 |
