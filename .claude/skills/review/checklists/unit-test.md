# 체크리스트: 단위 시험 (SWE.4)
기준: A-SPICE 프로세스 SWE.4 (사용 중인 A-SPICE 버전의 문서와 대조해 갱신할 것), 스킬 `unit-test`

| ID | 항목 | 근거 |
|---|---|---|
| UT-01 | 모든 `FUNC`에 시험이 연결되어 있다. | SWE.4 BP: 시험 명세, 추적성 |
| UT-02 | 모든 시험 케이스가 `UT` ID와 추적 항목(`FUNC`/`SWR`)을 갖는다. | 양방향 추적성 |
| UT-03 | 모든 시험 함수에 Doxygen 주석으로 목적, 입력값, 절차, 예상 출력값이 있다. | 프로젝트 규칙 |
| UT-04 | 입력 도메인에 동치 분할이 적용되었다. | 시험 기법 |
| UT-05 | 경계값(직전·경계·직후)이 시험되었다. | 시험 기법 |
| UT-06 | 입력 조합이 많은 곳에 PICT 조합을 사용했고 모델 파일이 보관되어 있다. | 프로젝트 규칙 |
| UT-07 | 설계에 정의된 모든 오류 반환 경로가 시험되었다. | SWE.4 BP: 시험 케이스 선정 |
| UT-08 | 모든 시험이 의미 있는 단언을 가지고 결과를 검증한다. | 프로젝트 규칙 |
| UT-09 | 커버리지만을 위한 의미 없는 시험이 없다. | 프로젝트 규칙 |
| UT-10 | 목표 커버리지(기본 100%)를 달성했고 측정 결과가 기록되어 있다. 예외는 근거와 승인이 있다. | SWE.4 BP: 커버리지 |
| UT-11 | MC/DC 목표가 있으면 `mcdc_coverage.sh` 결과로 모든 결정이 충족됨을 확인했다. | 프로젝트 규칙 |
| UT-12 | Stub/Mock이 인터페이스 너머에만 쓰였고 과도하지 않다. | 프로젝트 규칙 |
| UT-13 | 시험 결과(통과/실패)와 실패 조치가 기록되어 있다. | SWE.4 BP: 결과 기록 |
| UT-14 | 시험이 반복 실행 가능하고 결과가 결정적이다. | SWE.4 BP: 재현성 |
