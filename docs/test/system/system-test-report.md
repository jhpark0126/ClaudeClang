## 설계 내용
- 경계값: 입력 범위 바깥값(-1, max+1), 입력 나이 190/200/210 ms(안전 요구라 3-value, 해상도는 평가주기 10 ms로 가정), 100 ms 주기 최악 경우, 300 ms 이내 해제.
- 동치 클래스: 충돌 상태 4종, 접근위험 TRUE/FALSE/무효, 운전자 요청 유효/무효, 점화 TRUE/FALSE/무효, sensor_fault TRUE/FALSE/무효. 무효 클래스는 케이스당 하나만 넣었다(`STC-F-036`은 관찰용 보조 입력을 쓰며 비고에 명시).
- PICT 2-way: 충돌×위험(좌, 우)×점화×센서고장×요청 9건. 기대값은 가정 A-01(우선순위)과 A-17(FAULT·DEGRADED 규칙)에서 계산했다.
- WoW: 초기화 직후 첫 입력, DEGRADED·FAULT 중 충돌, 점화·센서고장 빠른 반복, 접근위험 토글, SW 시계 32비트 래핑.
- 결함 주입(오류 추정): 모든 입력에 극단 값을 계속 주입(`STC-NF-003`).

## 실행 상태 (정직한 기록)
- 이 문서는 **시험 명세**다. 56개 케이스를 시험 담당자 또는 자동화가 실행한 결과 기록은 아직 없다.
- 다만 기대값 오류를 일찍 찾으려고 PICT 9건(`STC-F-101~109`)을 임시 하니스로 실제 SW에 돌려 보았다: 출력 좌/우, 상태, 이유코드 집합이 9건 모두 기대값과 같았다(이유코드는 순서 없는 집합). 이 하니스는 저장소에 두지 않았고 결과는 공식 시험 결과가 아니다.
- 나머지 47건은 실행하지 않았다. 시스템 테스트 실행기(자동화)는 이후 이터레이션에서 `test/`에 추가할지 사용자가 정한다.
